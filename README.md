# 细胞内部漫游 · Inside the Cell

> **本项目基于** [@tim261004](https://github.com/tim261004) 的项目：https://github.com/tim261004/cell ，详见下方「关于本项目」。

一个可以直接在浏览器里打开的高中生物 **3D 细胞模型**，内容按人教版必修1整理，支持鼠标环绕、触控操作与细胞内部漫游，点击任意结构可查看知识点。

## 快速开始

### 本地离线使用

`desktop.html` 与 `mobile.html` 都是**单文件离线网页**，Three.js 已内嵌在文件里，不需要联网：

1. 下载 `desktop.html` 或 `mobile.html`；
2. 用 Chrome / Edge 打开（手机版也可用 Safari、Firefox 打开）；
3. 首次进入时需要生成 3D 场景，加载 2–4 秒属正常现象。

> 两个 3D 页面都是独立的单文件，单独拿走就能用。仓库里的 `index.html` 需要同目录下的两张预览图才能完整显示。

## 功能一览

### 一、细胞与结构

- **两种细胞**：动物细胞、植物细胞一键切换
- **15 类细胞结构**：细胞膜、细胞质基质、细胞壁、细胞核、线粒体、叶绿体、内质网、高尔基体、核糖体、溶酶体、中心体、液泡、细胞骨架、囊泡、过氧化物酶体
- **8 种胞内物质**：水、无机盐、糖类、脂质、蛋白质、核酸、ATP、酶
- 每个条目都包含：结构速览、组成与结构、主要功能、考点提醒、相关结构
- 另有「本章速记」：膜层分类、分泌蛋白运输路径、动植物差异、生物膜系统、高频易错点

### 二、细胞器的内部结构

| 细胞器 | 展示的内部结构 |
| --- | --- |
| 线粒体 | 外膜、内膜、向内折叠形成的嵴、基质、环状 DNA、核糖体 |
| 叶绿体 | 外膜、内膜、基粒（类囊体堆叠）、连接基粒的基质类囊体、基质、淀粉粒 |

- 线粒体在细胞中显示为**光滑的胶囊外形**；点开之后自动切换成**剖面模型**，露出嵴和内腔，关闭后恢复原状
- 选中线粒体或叶绿体时，会在模型上**实时标注**各个部件名称

### 三、分泌蛋白的合成与运输（8 步演示）

以**同位素标记法**的视角，分 8 步演示分泌蛋白从合成到分泌的全过程：

1. 用 ³H 标记的亮氨酸培养细胞
2. 核糖体：氨基酸脱水缩合，合成多肽
3. 内质网：初步加工，出芽形成囊泡
4. 囊泡①：沿细胞骨架运往高尔基体
5. 高尔基体：再加工、分类与包装
6. 囊泡②：运向细胞膜
7. 胞吐：分泌到细胞外
8. 结论：多种细胞器的协调配合

演示特点：

- **按步骤切换图层**：每一步只保留该步涉及的结构，其余结构淡出
- **³H 标记点**沿真实路径移动，旁边实时显示所在部位
- **放射性分布图**随时间变化（核糖体/内质网 → 高尔基体 → 分泌囊泡 → 细胞外），数据为参照 Palade 经典实验绘制的示意曲线
- 支持自动播放，也可暂停或手动切换步骤

### 四、跨膜运输实验室（第 4 章）

点击顶栏的「实验室」按钮打开，可通过按钮切换 6 种运输方式：

自由扩散、协助扩散（通道蛋白）、协助扩散（载体蛋白）、主动运输、胞吞、胞吐。

每种方式配有膜片段动画和知识卡，说明方向、是否需要转运蛋白、是否耗能、实例、影响因素与易错点。另外收录了**渗透作用与质壁分离**的要点。

在细胞膜、水、无机盐、糖类、蛋白质、ATP、囊泡这些知识卡的底部，可以直接跳转到对应运输方式。

### 五、生活的细胞

- **叶绿体随细胞质流动**：6 个叶绿体各自沿不同路径缓慢环流，互不碰撞，全程不穿过液泡与细胞膜
- 进入「细看」时流动自动暂停，方便观察结构

## 交互方式

操作采用**三段式**，避免一点击就弹出面板挡住模型：

| 动作 | 结果 |
| --- | --- |
| 点场景里的结构 | 进入**细看**：镜头贴近、切成剖面（线粒体）、显示部件标注，但不弹面板 |
| 滚轮 / 双指 | 在细看状态下继续放大，看清嵴、基粒等细节 |
| 点部件标注，或点底部工具条上的名称 | 展开**详细说明** |
| 关闭说明面板 / 按 `Esc` | 退出细看，结构恢复正常状态 |

### 桌面版

- 鼠标拖拽环绕，滚轮缩放（可贴近到看清嵴和基粒），单击查看，双击聚焦
- 进入漫游后用 `WASD` 移动、`Q/E` 升降、鼠标环视、`Esc` 退出
- 漫游中滚轮或 `+` / `-` 可放大缩小视野
- 快捷键：`T` 标签开关、`H` 帮助、`1` / `2` 切换动物 / 植物细胞
- 路径演示中：`←` / `→` 切换步骤，空格暂停 / 继续

### 手机版

- 单指旋转，双指缩放（环绕和漫游状态下都可以），轻点查看
- 漫游时用左下摇杆移动、拖动屏幕环视、右下按钮升降，双指捏合放大缩小
- 路径演示用底部步骤条的「‹ ›」切换，「收起」可把面板压到最小

### 全屏

点击顶栏的全屏按钮可进入全屏；浏览器不支持全屏时，会自动切换为**沉浸模式**（隐藏顶栏与底部列表），再次点击退出。

## 内容范围

- **主体内容（第 3 章）**：细胞膜、细胞质、细胞核，以及各类细胞器之间的分工合作。
- **跨章补充**：8 种「胞内物质」主要对应 **第 2 章《组成细胞的分子》**（水、无机盐、糖类、脂质、蛋白质、核酸）与 **第 5 章《细胞的能量供应和利用》**（ATP、酶）。它们作为理解细胞结构的背景知识收录，单独归入「胞内物质」分类，不与第 3 章的考点混在一起统计。
- **拓展内容**（如过氧化物酶体、中心体与纤毛）已在文案中标注「拓展」。

## 已知限制

- **教学示意模型**：细胞器的大小、数量、位置经过艺术化处理，**不按真实比例**
- 细胞器数量固定（如 6 个线粒体、6 个叶绿体），只用于表达结构关系，不代表真实数量
- 放射性分布曲线是示意数据，用于展示运输顺序，并非原始实验数值
- 「超微结构」只做到光镜/亚显微水平的示意，不涉及分子细节
